# --------------------

# 

# How to run (Binary)

# 

# 1\. Open the Binary folder within the provided ZIP file.

# 2\. Run "Prototype Two - UnityFile.EXE"

# 3\. When finished use "alt"+"F4" to exit

# 

# --------------------

# 

# How to Run/Build (Unity Editor)

# 

# 1\. Open the "Prototype Two - UnityFile" file within the unity editor

# 2\. Within the assets window select <Scenes> - <Main Menu> - Open the main menu scene.

# 3\. Press play at the top of editor (or "CTRL" + "P")

# 4\. To build press "CTRL" + "B"

# 5\. If asked select or create a Build folder within the project file 

# 6\. Finally build and execute the "Prototype Two - UnityFile.EXE" File
